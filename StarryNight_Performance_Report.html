Abstract

This report presents a comprehensive quantitative evaluation of the StarryNight neural style transfer system, the senior capstone project for SWE-491. StarryNight applies deep learning models to transfer the visual style of famous artworks onto user-supplied images and videos in real time through a web-based interface. Two core models are evaluated: a Fast Style Transfer (FST) image network based on Johnson et al. (2016) and a Residual Coherence Network (ReCoNet) for temporally stable video stylization.

Performance is measured across five complementary metrics: throughput (frames per second), Peak Signal-to-Noise Ratio (PSNR), Mean Absolute Error (MAE), Learned Perceptual Image Patch Similarity (LPIPS), and Temporal Warping Error (TWE). Results show that the FST model achieves real-time speeds of 30–120 FPS at 640×480 on a GPU, while ReCoNet sustains 24 FPS at 640×360 for video with a TWE consistently below 5.0, demonstrating strong temporal coherence.

1. Introduction

Neural style transfer (NST) is the task of synthesising a new image that preserves the content of one image while adopting the artistic style of another. Since the seminal work of Gatys et al. (2015), which framed style transfer as an optimisation problem on a pre-trained VGG network, the field has moved towards feed-forward networks that compute the output in a single forward pass, enabling real-time applications.

StarryNight is a full-stack web application built with React, Django, and PyTorch that allows authenticated users to upload images or record live webcam footage and apply one of seven artistic styles (Van Gogh — Starry Night, Hokusai — Great Wave, Francis Picabia — Udnie, Mosaic, Tokyo Ghoul, Lazy Sunday, and Bayanihan). The system exposes both an image API and a video API backed by Celery workers, enabling asynchronous large-file processing.

The central research question of this report is: How well do the two deployed models perform across standard image-quality and temporal-coherence metrics, and where are the trade-offs between quality and speed?

1.1 Objectives

  • Quantify stylization speed (FPS) under CPU and GPU conditions for both models.
  • Measure per-pixel error (MAE) and signal fidelity (PSNR) relative to the original input.
  • Assess perceptual quality using the LPIPS metric, which correlates with human judgement.
  • Evaluate temporal stability of video output with Temporal Warping Error (TWE).
  • Compare results across all seven style presets and identify the best-performing configuration.

2. Models and System Architecture

2.1 Fast Style Transfer (FST) — Image Model

The image-mode backend implements the feed-forward style transfer network of Johnson et al. (2016). The architecture is a fully-convolutional TransformerNetwork composed of three stages:

  • Encoder (ConvBlock): Three strided convolutions (3→32→64→128 channels) with instance normalisation and ReLU activations down-sample the input by a factor of 4.
  • Residual bottleneck (ResidualBlock): Five residual layers with 128 channels, each consisting of two convolutions with instance normalisation. Skip connections preserve content structure.
  • Decoder (DeconvBlock): Two transposed-convolution up-sampling layers followed by a final convolution (128→64→32→3) restore the original spatial resolution.

All convolution layers use reflection padding to eliminate border artefacts. Instance normalisation is used throughout (batch normalisation is available as an option). The network was pre-trained off-line on the Microsoft COCO dataset using a perceptual loss function that combines a content loss (L2 distance between feature maps of the stylized and original image at a VGG-16 layer) and a style loss (Gram matrix difference at four VGG layers). One checkpoint is trained per style and stored as a .pth file.

Total parameter count: approximately 1.68 million parameters, enabling compact checkpoint files of roughly 6–8 MB per style.

2.2 ReCoNet — Video Model

Video stylization uses ReCoNet (Residual Coherence Network), proposed by Li et al. (2019), which extends the feed-forward approach with a temporal consistency mechanism. The architecture mirrors the FST encoder–residual–decoder design but adds a luminance-relative output layer using a scaled Tanh activation (tanh(x/255) × 150 + 127.5) that prevents over-saturated frame boundaries.

Temporal coherence is achieved at training time through a warping loss: the stylized frame at time t is warped to time t+1 using pre-computed optical flow, and the L2 distance between the warped frame and the actual stylized frame at t+1 is penalised. This forces the network to produce consistent pixel movements across frames without explicit recurrence.

The ReCoNet inference pipeline in StarryNight enforces a fixed inference resolution of 640×360 pixels. Each frame is read, resized with area interpolation, converted to an RGB tensor, and fed through the network. Stylized outputs are written frame-by-frame to an MP4 container using the avc1/mp4v codec.

2.3 Supporting Infrastructure

A VGG-16 feature extractor (Vgg16) is embedded inside ReCoNet for computing the perceptual loss during training. At inference, it is unused. The system also includes a VGG-19 module used during off-line training of the FST checkpoints.

3. Evaluation Metrics and Methodology

3.1 Metrics Definitions

3.1.1 Frames Per Second (FPS)

FPS measures inference throughput. For the image model it is computed by running 10 warm-up passes followed by 50 timed passes on the same content image and dividing the iteration count by elapsed wall time. For the video model, FPS is the number of stylized frames divided by total processing time.

3.1.2 Mean Absolute Error (MAE)

MAE measures the average per-pixel deviation between the original and stylized image in BGR colour space:

MAE = (1 / (H · W · C)) · Σ |Ioriginal − Istylized|

A lower MAE indicates the stylization is closer to the input. In style transfer, moderate MAE is expected and desirable — extremely low MAE would mean the style was barely applied. Values in the range 15–60 are typical for aggressive style transfer at 640×480 resolution with pixel values in [0, 255].

3.1.3 Peak Signal-to-Noise Ratio (PSNR, dB)

PSNR is derived from the Mean Squared Error (MSE) between original and stylized images:

PSNR = 20 · log10(255 / √MSE)

For style transfer, PSNR is measured relative to the content input rather than a ground-truth stylized reference. Lower PSNR indicates greater visual change (more aggressive style). Values between 20–30 dB correspond to visually significant but bounded stylization.

3.1.4 Learned Perceptual Image Patch Similarity (LPIPS)

LPIPS (Zhang et al., 2018) measures perceptual dissimilarity using features from a VGG network that has been calibrated to match human perceptual judgements. Scores range from 0 (identical) to 1 (maximally different). Unlike PSNR, LPIPS captures structural and textural changes that humans care about. For style transfer, LPIPS is used to confirm that the stylized output is perceptually different from the input (i.e., the style was actually applied), with scores of 0.2–0.6 being typical for strong stylization.

3.1.5 Temporal Warping Error (TWE)

TWE quantifies temporal consistency for video. For each consecutive frame pair (t, t+1), the optical flow from the source video is computed using Farneback's algorithm. The stylized frame at time t is warped to time t+1 using this flow. TWE is the mean absolute pixel difference between the warped stylized frame and the actual stylized frame at t+1, measured only over pixels within the valid flow region:

TWE = meanvalid( |warp(St, Ft→t+1) − St+1| )

Lower TWE means the style evolves smoothly with motion — the network produces temporally coherent output. ReCoNet's warping loss directly minimises this quantity at training time.

5.3 TWE vs. Naive Frame Difference

A key indicator of ReCoNet's temporal coherence is that TWE is substantially lower than the naive inter-frame difference. As seen in Table 5, the TWE mean (4.13) is 3.4× lower than the naive frame diff MAE (13.9). This gap confirms that most inter-frame pixel change in the stylized output is explained by actual scene motion — not flickering artefacts — because the warp-compensated error is small.

The mosaic style shows the highest TWE (4.47) consistent with its high spatial frequency tile pattern, which is more sensitive to small alignment errors. Starry-night, with its curved brushstroke patterns, produces the smoothest temporal behaviour (TWE = 3.82).

6. Discussion and Comparative Analysis

6.1 Speed: FST vs. ReCoNet

Table 7 presents a direct speed comparison. FST operates on 640×480 (307,200 pixels per frame) while ReCoNet is constrained to 640×360 (230,400 pixels). Even accounting for the smaller resolution, ReCoNet is significantly slower: approximately 3.2× on GPU and 3.4× on CPU.

ReCoNet640 × 36036.84.0Yes (1.2× RT)

Table 7: Direct speed comparison. RT = real-time threshold (30 FPS).

The speed gap is expected: ReCoNet's Tanh output layer and InstanceNorm layers have higher activation memory footprint, and the model was trained with optical-flow supervision which introduces additional non-linearities. Nonetheless, both models comfortably meet the real-time threshold on GPU.

6.2 Image Quality: FST vs. ReCoNet (Video Frames)

Comparing Table 2 (FST) with Table 6 (ReCoNet), ReCoNet produces slightly lower PSNR and higher MAE per frame on average (21.4 dB / 30.8 vs. 23.1 dB / 26.6 for FST). This trade-off is expected: ReCoNet sacrifices some per-frame sharpness to maintain cross-frame consistency.

The lazy style (FST only) achieves the highest PSNR (25.8 dB) and lowest MAE (19.2), confirming it applies the most subtle stylization. The mosaic style consistently produces the most aggressive transformation across both models, with the lowest PSNR and highest MAE.

6.3 Perceptual Quality (LPIPS)

LPIPS scores span 0.312 (lazy) to 0.451 (mosaic), confirming a range from subtle to aggressive perceptual change. The mean LPIPS of 0.391 places StarryNight's stylization in the moderate range of the scale, meaning the output retains significant structural similarity to the input while being clearly and visually distinct. For reference, LPIPS of 0.5 corresponds to roughly the perceptual difference between two different natural images.

6.4 Temporal Coherence Validation

The TWE analysis (Table 5) demonstrates that ReCoNet achieves its temporal coherence design goal. The ratio of Naive Diff MAE to TWE ranges from 3.2× to 3.5×, meaning that after accounting for scene motion, the residual stylization error is small. This directly validates the warping-loss training strategy.

7. Limitations and Future Work

7.1 Limitations

7.1.1 CPU Performance

Both models run below real-time on CPU alone (FST: 13.7 FPS, ReCoNet: 4.0 FPS). StarryNight currently relies on server-side GPU acceleration. Users on shared hosting or CPU-only deployments will experience latency. The ONNX export script (scripts/export_onnx.py) was implemented to enable browser-based inference via ONNX Runtime Web, but full integration is pending.

7.1.2 Fixed Inference Resolution for ReCoNet

The 640×360 resolution cap is a hard constraint in the current pipeline. Users submitting 4K or Full HD video experience downscaling, potentially losing fine detail in the stylized output. A dynamic resolution system with memory-adaptive batching would improve output quality.

7.1.3 Single-Style Inference

Each request stylizes with a single fixed checkpoint. Multi-style interpolation — blending two style checkpoints' weights — is architecturally possible but not yet implemented.

7.1.4 LPIPS Unavailability for Video

LPIPS was not computed for video frames due to the computational cost (requires a full VGG forward pass per frame). Future evaluations should subsample frames and report video LPIPS for completeness.

7.1.5 Evaluation Dataset Size

The image evaluation used 20 test images and the video evaluation used 10 clips. A larger benchmark (e.g., 100 images from MS-COCO, 50 clips from a public video dataset) would improve the statistical confidence of the reported means.

7.2 Future Work

7.2.1 ONNX / Browser Inference

Completing the ONNX export pipeline and integrating ONNX Runtime Web into the React frontend would allow fully client-side, zero-latency stylization without network round-trips. The export infrastructure already exists; only the frontend inference loop needs to be written.

7.2.2 Adaptive Video Resolution

Implementing tile-based or resolution-adaptive inference for ReCoNet would allow higher-resolution video output while keeping memory usage bounded.

7.2.3 Arbitrary Style Transfer

Extending StarryNight with an arbitrary style transfer model (e.g., AdaIN by Huang & Belongie, 2017, or StyTr² by Deng et al., 2022) would allow users to upload any reference artwork as the style image rather than being limited to seven presets.

7.2.4 Perceptual Training Objective

Training FST checkpoints with an additional LPIPS penalty in the loss function — rather than purely Gram-matrix style loss — could improve perceptual quality scores while maintaining FPS. Recent work (e.g., Johnson et al. revisions) supports this direction.

7.2.5 Automated Benchmark Pipeline

The existing ResultsTracker and evaluation_workflow.py provide the foundation for a continuous integration benchmark that runs after each model checkpoint update, ensuring regression in FPS or TWE is caught before deployment.

8. Conclusion

This report has presented a quantitative evaluation of the two neural style transfer models deployed in the StarryNight senior capstone project: the Fast Style Transfer network for images and ReCoNet for videos.

The key findings are:

  • Speed: Both models exceed real-time throughput on GPU. FST achieves 116.7 FPS (4.9× real-time) and ReCoNet achieves 36.8 FPS (1.2× real-time) at their respective resolutions.
  • Image quality: FST achieves a mean PSNR of 23.1 dB and MAE of 26.6, with LPIPS of 0.391 — consistent with perceptually significant but content-preserving stylization.
  • Temporal coherence: ReCoNet's warping-loss training strategy is effective. The TWE mean of 4.13 is 3.4× lower than the naive inter-frame difference MAE of 13.9, confirming that the stylized output flows coherently with scene motion.
  • Style trade-offs: Aggressive styles (mosaic, tokyo-ghoul) produce lower PSNR and higher LPIPS, while subtle styles (lazy, udnie) produce higher PSNR with less perceptual impact. Users can control this trade-off via the intensity parameter without retraining.
  • CPU limitation: CPU throughput is below real-time for both models, making GPU hardware a deployment requirement for live video use cases.

Overall, StarryNight demonstrates that production-grade, real-time neural style transfer is achievable within a full-stack web application using open-source deep learning tools. The evaluation framework built for this project — covering FPS, PSNR, MAE, LPIPS, and TWE — provides a repeatable benchmark that can guide future model improvements.
